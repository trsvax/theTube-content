Everyone else: "AI writes code faster so I can ship more code." Then they worry about hallucinations, bugs, security holes in the generated code.

Me: AI helps me design a system where there's less code to write in the first place. The auth is infrastructure. The logging is structural. The scaling is built in. There's nothing to hallucinate because there's nothing to generate.

They're using AI to produce code. I'm using AI to eliminate it.

The t-shirt says "60 lines of code."
